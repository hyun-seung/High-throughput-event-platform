# 문서 안내

**번호순으로 전부 읽을 필요는 없습니다.** 현재 설계·진행 상황은 아래 핵심 3개로 확인합니다. 나머지는 작업할 때 찾는 상세 계약 또는 이관 전 설계·검증 기록입니다. 번호는 작성 순서이며 중요도나 읽는 순서가 아닙니다.

## 1. 먼저 읽을 문서 3개

다음 문서는 장애 재현, 성능 비교, 과거 결정 이유를 찾을 때 필요합니다. 원시 결과를 해석하는 조건·실패 기록이 있어 삭제하지 않습니다. **전부 읽어야 현재 시스템을 이해할 수 있는 필수 문서가 아닙니다.**

| 초기 개발 순서·단계별 설명·논의 경과 | 02·05·08. 신규 정책·순서는 00·01·53에서 확인 |

## 4. 앞으로 문서를 늘리는 기준

- 기능을 고치면 해당 주제 문서를 갱신합니다. 커밋마다 새 진행 문서를 만들지 않습니다.
- 진행 상황·미완료 목록은 01, 정책은 00, 신규 케이스별 호출 흐름은 53에서 각각 관리합니다. 04는 이관 전 전체 흐름과 검증 근거로 보존합니다.
- 새 문서는 독립적인 연동 계약·운영 절차·중요한 설계 결정이 생길 때 추가합니다.
- 시험 수치와 실패 원인은 검증 결과에 보존하고, 설명 문서에는 결론·조건·근거 링크를 남깁니다.
- 정책 변경 시 현재 문서 본문을 고칩니다. 예전 결론 아래에 정정 문구만 계속 붙이지 않습니다.

이관 전 문서는 당시 코드·시험 결과의 근거와 링크를 보존하기 위해 유지합니다. **현재 설계를 보려면 위 3개만 읽으면 됩니다.** 필요할 때 해당 주제의 상세 문서만 찾습니다.
