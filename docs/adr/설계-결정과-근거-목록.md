# 설계 결정과 근거 목록

## 작성 형식

파일명은 `ADR-NNN-한글-제목.md`를 사용합니다. 상태는 `Proposed`, `Accepted`, `Superseded` 중 하나입니다.

```markdown
# ADR-NNN 제목

- Status: Proposed
- Date: YYYY-MM-DD

## 문제
## 검토한 대안
## 결정
## 선택 이유
## 장점과 제약
## 장애 상황
## 복구 방법
## 성능 영향
## 검증 방법
```

`검증 방법`에는 결정이 맞는지 확인할 자동 테스트, 장애 테스트, 메트릭을 적습니다. `선택 이유`에는 공식 문서의 URL·검토 버전·날짜와 프로젝트의 판단을 구분해 기록합니다. `장점과 제약`에는 보장이 성립하는 조건과 남는 실패 사례를 포함합니다. 요구사항이나 운영 설정이 미확정이면 `Proposed`로 남깁니다.
